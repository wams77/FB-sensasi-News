# Sensasi News Bot

AI News Bot menggunakan:

- Groq
- GitHub Actions
- Facebook Graph API

## Feature

- Football News
- K-Entertainment
- AI Viral Score
- AI Rewrite
- Auto Hashtag
- Auto Facebook Post
- Duplicate Detection
- Posting History

## GitHub Secrets

GROQ_API_KEY

FACEBOOK_PAGE_ID

FACEBOOK_ACCESS_TOKEN

## Run Local

```bash
pip install -r requirements.txt

python app/bot.py
```

GitHub Actions akan menjalankan bot setiap 30 menit.
